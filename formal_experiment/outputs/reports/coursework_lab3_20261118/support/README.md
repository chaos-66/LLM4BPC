## 数据与方法

UCI Wine Quality，DOI 10.24432/C56S3T，CC BY 4.0。
2026-11-18 从官方 ZIP 下载，仅使用 `winequality-red.csv`。
原始 1,599 行、11 个输入；完整记录去重 240 条后 1,359 行。
`quality >= 7` 为正类；815/272/272 分层训练/验证/测试，seed=42。
FP:FN 成本假设为 1:3；三个模型均仅在验证集搜索同样的 19 个阈值。
参数、数据和阈值搜索规则未根据测试表现改变。

验证集选出随机森林 t=0.30；测试 F1 0.5316、FP+3FN=69。
逻辑回归 t=0.30 的测试 F1 0.5974、成本59更好，该事实如实报告，
没有事后将其冒称为测试前选出的模型。默认 t=0.50 的比较另表列出。

## 执行和修正

第一次真实运行在输出 manifest 时遇到 XGBoost 默认参数 `missing=NaN`
不能被严格 JSON 序列化的问题。将该参数记为字符串后，第二次运行完整通过，
两次保存的预测逐字节一致。PDF 视觉检查又发现一幅图标题过长，缩短后重新运行
最终代码并重新生成报告；最终预测与前次逐字节一致。
临时运行目录保留在工作区 `.tmp/classification_lab3/`，未覆盖前次结果。

`evidence/` 是最终完整运行 `run_v3` 的逐字节副本（不重复分发原 CSV）。
manifest 中包含原 CSV 哈希，原 CSV 可由提交代码从 UCI 官方获取并校验。
CSV 许可允许复用，源文件未被修改。清单中的本机运行路径只用于追溯；复现时使用
报告和代码顶部的相对路径命令即可。代码源以 LF 保存，避免平台换行影响哈希。
