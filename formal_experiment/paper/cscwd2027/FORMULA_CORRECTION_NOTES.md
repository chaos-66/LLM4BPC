# CSCWD 论文 IV.C 公式修正说明

本批次只修正用户提供论文的 IV.C（Compliance Checking）公式及相应记号说明。实验程序、参数、Gold、预测、结果和表格没有改变。小节外正文保持原样；此前清理的原第 100、102 行空白行尾空格继续保留。原始附件未覆盖。

## 当前转写依据

用户于 2026-10-11 提供的第 2–5 张原公式截图为本次符号、字体和条件的直接依据。第 1 张是此前有误的 `bs-obj` 呈现，不能作为原公式抄录依据。本地 Sun 作者稿 `references/papers/Sun_2024_Design_time_BPC.pdf` §4.3、Definition 4–7、印刷页码 13–14 用于对应公式和理解 business object；不能只依赖 PDF 文本抽取结果判定下划线或连接号。

## 对先前转写的纠正

| 项目 | 当前写法 |
|---|---|
| 业务对象 | `\mathit{bs\_obj}`，为原图中斜体、字面下划线的 `bs_obj`；不是 `bs-obj` 或下标 `bs_{obj}` |
| 相似度 | 保留原图的斜体 `sim`，不改成直立体 `\operatorname{sim}` |
| 匹配分数 | 原图的 `F(r,m,\tau)`，不改成 `M` 或花体 `\mathcal{F}`；完整保留原来的两个求和比率和 `max` |
| 违规函数 | 斜体 `action_violation`、`actor_violation`、`order_violation`，下划线为字面下划线；不缩写为 `V` |
| 函数参数 | 原文逗号、模型 `m`、actor 阈值 `\vartheta`；没有分号。小节说明其与实验设置 `\theta` 的记号对应 |
| Actor 原式 | 原样保留 `\exists r'`、`sim(r,r')<\vartheta`，以及 `R`、`C` 中的量词、映射和严格 `>\gamma`；保留原图使用的局部变量名 |
| Order 原式 | 完整保留原来分子中的长集合、两端映射、正向属于 `F_m` 且反向不属于 `F_m`、`U` 定义中的两个严格 `>\gamma` |
| 拆行方式 | 只在原表达式内换行；不新增 `m_A`、`m_O`、`B`、`I`、`S` 等辅助比率或集合名，不改写为极值/全称条件 |

`bs_obj(A_m\cup E_m)` 表示从活动和事件标签取得的业务对象集合。它与 `R_m`（流程执行者集合）合并，构成 `C` 定义中的候选范围，随后保留原式的动作关联筛选条件。

空输入、候选缺失及无可评价顺序关系属于本项目既有实现约定，仍放在小节末尾单独说明，不冒称 Sun 原式的附加条件。本次文档纠正不改变这些约定的执行结果。
